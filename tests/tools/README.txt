下载链联网校验工具
================================================================================

  sim_download.py —— 复刻 lib/common.sh 中 fetch() 的下载优先级链，对清单里
  全部组件/版本做真实的 HTTP Range 联网探测（只取 1 字节，不下载整个包）。

  它验证三件事：
    1) 官方源是否可用、命中的是第几个官方 URL（首选还是备用）
    2) 官方全败时，镜像兜底 URL 构造是否正确、是否可达
    3) 镜像站的文件覆盖率（哪些新版本还没同步）

  用法：
    python3 sim_download.py

  依赖：requests
    pip3 install requests

  说明：探测时使用 verify=False，对应安装器里的 wget --no-check-certificate
  （镜像站证书链在严格校验下会报错）。

  最近一次实测（2026-10-22）：
    官方源38/38 全部命中，0 失败
    首选官方 URL 命中 37/38（ImageMagick 7.1.2-25 走第2 个源 GitHub）
    镜像站已同步 25/38，尚未同步 13（新 PHP 6 个 + MySQL 4 个 + MariaDB 3 个）

  与 fetch_sim.sh 的区别：
    fetch_sim.sh   —— 不联网，用 stub wget 验证 fetch() 的优先级顺序逻辑
    sim_download.py —— 真实联网，验证各上游站点的实际可达性
